# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this repo is

This is a *data* repo, not a code repo. It's the mod configuration for a Skyrim Special Edition
install managed by [`skrim`](https://github.com/arecker/skrim), a CLI tool that installs/uninstalls
mods idempotently based on a config file. There is no application code here to build, lint, or test —
this repo just holds `mods.conf`, the generated `mods.lock.json`, and the downloaded mod archives.

The `skrim` tool itself is developed in a sibling repo at `../skrim` (also on this machine). If a task
involves changing `skrim`'s behavior rather than this repo's mod list, work in `../skrim` instead.

## Running skrim

`skrim` is aliased in `~/.bashrc` to `$HOME/src/skrim/venv/bin/skrim`. From this directory:

```
$ skrim -c mods.conf
```

Other flags (see `../skrim/README.md` for the full story):

- `-v` — debug logging
- `-d` — drop into an interactive debugger on error
- `--again` — re-prompt for mod install options instead of reusing saved answers from the lockfile
- `--pave` — completely uninstall everything and reset the game
- `-h` — help

Running it again after editing `mods.conf` is the normal workflow — it diffs against `mods.lock.json`
and only installs/uninstalls what changed.

## mods.conf structure

INI-style config. The `[skrim]` section holds paths (downloads dir, game dir, `Plugins.txt`, `Skyrim.ini`).
Every other section is one mod, keyed by an arbitrary short name:

```
[mod_short_name]
filename = <exact filename of the archive in downloads/>
requires = other_mod_a, other_mod_b
```

- `filename` must exactly match a file in `downloads/` (this is how `skrim` finds the archive to install).
- `requires` is a comma-separated list of other section names. If a required mod's config changes,
  dependents get reinstalled too.
- **Load order is file order** — the order mods appear top-to-bottom in `mods.conf` is the load order.
  There's no separate load-order mechanism.

## mods.lock.json

Generated by `skrim`. Tracks what's currently installed and which files each mod placed where. Never
hand-edit or delete this — `skrim` uses it to compute diffs on the next run and to know what to clean
up on uninstall/`--pave`.

## downloads/

Holds the raw mod archives (`.7z`, `.zip`, `.rar`) referenced by `filename` in `mods.conf`. This
directory is gitignored (`downloads/.gitignore` excludes everything but itself) — the archives are not
tracked in git, only the config that references them.

New archives are downloaded manually from Nexus Mods into this folder. A Nexus API key is available
via `pass nexus/api-key` if a task needs to hit the Nexus API directly (e.g. to check for mod updates).
